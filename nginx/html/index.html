Список приложений

Через этот gateway приложения публикуются по префиксам путей через один общий nginx.

  • Foxy Chat Комнаты, сообщения и Markdown по префиксу /foxy-chat/.
  • chess-quest Шахматный квест доступен по префиксу /chess-quest/.
  • Тест таблицы умножения Знайка Проверка таблицы умножения и деления.
  • pc-man Игра доступна по префиксу /pc-man/.
